# Начало

EasyDeck — программа для макро-панелей: тех самых коробочек с экранами вместо
клавиш, которые стоят рядом с клавиатурой и переключают сцену, глушат микрофон
и запускают что угодно ещё. Она свободная, работает без учётной записи и без
облака, и её можно расширять плагинами.

Эта документация описывает то, что программа умеет сегодня. Программа в стадии
ранней разработки: часть описанного здесь ещё меняется от версии к версии.

## Что нужно

Дека **FIFINE AmpliGame D6** — 15 клавиш 3×5 с экранами 112×112. Это клон
Stream Dock на контроллере SINOWEALTH; программа говорит с ней по протоколу,
снятому с USB-захвата фирменного приложения, а не угаданному.

Дека не обязательна. Страницу деки можно открыть в браузере на телефоне или
планшете в той же сети — см. [Сеть, файлы и журнал](../network/).

## Установка

Скачайте установщик со страницы релизов или соберите из исходников:

```bash
pnpm install
pnpm build
pnpm --filter @easydeck/app start
```

Программа состоит из двух частей в одном процессе: **демон**, который держит
панель и выполняет макросы, и **окно настроек** — обычная веб-страница,
которую демон отдаёт. Поэтому одна и та же настройка выглядит одинаково в окне
на компьютере и в браузере на планшете.

## Первый запуск

При запуске программа ищет деку по USB и создаёт профиль по умолчанию. Если
дека не найдена, всё остальное продолжает работать: макросы, переменные,
плагины и сетевые деки от USB не зависят.

Дальше стоит прочитать [Профили, папки и клавиши](../profiles/) — это
основные понятия, на которых держится всё остальное.

## Куда что положено

| Что | Где |
| --- | --- |
| Профили | папка `profiles` внутри данных приложения |
| Настройки плагинов | папка `plugins` |
| Ваши картинки | папка `icons` |
| Журнал | папка `logs` |

Открыть любую из них можно прямо из настроек — там есть кнопки «Открыть
папку». Подробнее в разделе [Сеть, файлы и журнал](../network/).
