# Что даёт хост

`start(host)` получает единственный объект, через который плагин общается с
программой. Всё в нём — запрос, а не доступ к внутренностям: тот же контракт
будет работать в день, когда плагины поедут в отдельный процесс.

## Состояние и настройки

```ts
host.setStatus('ready', { en: 'Connected', ru: 'Подключено' });
host.setStatus('error', { en: 'No application id', ru: 'Нет ID приложения' });

const settings = host.settings();
host.onSettingsChanged(() => this.connect());

await host.remember('token', granted);
```

`setStatus` рисует лампочку рядом с плагином в настройках. Состояния: `off`,
`connecting`, `ready`, `error`. Сообщение стоит писать так, чтобы из него было
понятно, что делать.

`remember` записывает настройку самим плагином — так сохраняется токен, который
выдал OAuth. Осторожно: запись настройки поднимет `onSettingsChanged`, и
плагину нужен признак «это я сам», иначе он переподключится в ответ на
собственную запись.

## Переменные

```ts
host.setVariable('ed.obs.scene', 'Игра');
host.setFamily('ed.discord.members', channelId, 4);
host.setFamily('ed.discord.members', '', 4);   // «тот, где вы сейчас»
```

```ts
host.onWatched((keys) => {
  // Только то, что кто-то действительно читает — и только с открытой страницы.
  this.watching = keys.map(parseVariableKey).filter(…);
});
```

`onWatched` — это сделка. Программа рассказывает, какие переменные читаются
прямо сейчас, а плагин взамен не публикует всё подряд. Без неё, чтобы показать
одно число, пришлось бы опрашивать каждый голосовой канал каждого сервера.

## Списки для полей

```ts
host.provideOptions('channels', async () => this.channels);
```

Параметр с `optionsFrom: 'channels'` спросит это при открытии редактора. Список
берётся из работающей программы, поэтому пользователь выбирает сцену из тех, что
у него есть, а не печатает её имя по памяти.

## Расписание

```ts
const ticker = host.update(15_000, async () => this.poll());
ticker.every(0);   // остановить
ticker.stop();
```

Своего `setInterval` быть не должно: таймер внутри плагина хост не видит, и
остановка плагина превращается в вежливую просьбу. Регистрируйте столько
расписаний, сколько у плагина ритмов — быстрое для показаний, медленное для
списка.

Такт, который ещё выполняется, когда подошёл следующий, пропускается, а не
ставится в очередь. Такт, упавший с ошибкой, пишется в журнал и ничего не меняет:
решать, сломан ли плагин, — дело `setStatus`, а не хоста.

## Живые картинки

```ts
host.provideSurface('ed.discord.speakers', async (request) => {
  if (nothingToDraw) return undefined;
  return { source: svgText, id: `${cols}x${rows}|${who.join(',')}` };
});
```

`request` несёт параметры, размер в клавишах (`cols`, `rows`) и список клавиш,
для которых рисуется. Ответ — SVG-текст или data-URL.

**Ответить `undefined` — нормально.** Ничего не играет, OBS закрыт: клавиша
покажет то, что ей дали как обычную картинку. Это не ошибка и как ошибка не
сообщается.

**`id` — это личность картинки.** Кадр с тем же `id`, что и предыдущий, панель
не будет записывать заново. Для обложки альбома `id` обязателен — она висит на
экране часами; для кадра графика он бессмысленен, и его лучше не давать.

```ts
host.redraw();   // «мои картинки изменились, спросите заново»
```

Поверхность спрашивают только во время перерисовки, а перерисовка происходит
из-за того, что подвинулось что-то другое. Картинке, которая живёт по своему
расписанию и не привязана ни к какой переменной, нужен `redraw`.

```ts
host.onWidgets((widgets) => { … });
```

Что сейчас на экране — включая чужие виджеты. Это позволяет не платить за то,
чего никто не видит: OBS не просят присылать уровни громкости, пока на странице
нет ни одного индикатора.

## Прочее

```ts
host.openExternal('https://passport.yandex.ru/...');   // браузер пользователя
host.route('/callback', handler);                      // путь на локальном сервере
host.log('warn', 'Could not read the voice channel');  // в общий журнал
host.setWidgetParam(buttonId, 'source', 'Камера');     // перенастроить виджет на клавише
```

`route` занимает путь `/plugin/<id>/<path>` — только на петле, никогда наружу.
Код OAuth, прилетевший на открытый порт, — это код, который может забрать любой
в этой сети.

`setWidgetParam` кладёт настройку **поверх** того, что говорит профиль, а не в
сам профиль: нажатие клавиши, которое правит документ, привело бы к тому, что
экспорт увозит последнее нажатое вместо того, что человек настроил.
